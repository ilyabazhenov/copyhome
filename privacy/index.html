Политика конфиденциальности CopyHome

CopyHome — приложение для macOS, которое делает бекапы ваших серверов на ваш Mac. Оно не собирает сведений о вас и никуда их не отправляет: копии идут напрямую с ваших серверов на ваш Mac и в хранилища, которые вы подключили сами.

Обновлено 18 октября 2026

Коротко

  • В CopyHome нет аналитики, телеметрии, отчётов о сбоях и рекламы.
  • У CopyHome нет своих серверов. Разработчик не получает ни ваших бекапов, ни паролей, ни сведений о том, как вы пользуетесь приложением.
  • Всё, что приложение хранит, лежит на вашем Mac.

Что хранится на вашем Mac

  • Настройки. Проекты, адреса серверов, имена пользователей, базы, каталоги, расписание и подключённые хранилища. Файл настроек лежит в ~/Library/Application Support/fast-backup и доступен только вашей учётной записи macOS.
  • Пароли и ключи. Пароли баз данных и SSH, ключи доступа S3, токены Яндекс Диска и Google Диска и пароль шифрования бекапов. Они зашифрованы ключом из Связки ключей macOS и не хранятся в открытом виде.
  • Бекапы и история. Файлы копий лежат в папке, которую вы выбрали, а журнал запусков и отпечатки ключей ваших серверов хранятся в папке приложения. Восстановление и пробная проверка дампа тоже идут только на этом Mac: в локальной базе, в Docker или в папке.
  • Файл для переезда на новый Mac. Появляется, только когда вы сами сохраните настройки. Если взять в него пароли, он шифруется вашим паролем в формате age. Токены Яндекс Диска и Google Диска в него не попадают.

С чем соединяется приложение

  • Ваши серверы по SSH. CopyHome снимает дампы баз и архивы каталогов и пишет их потоком прямо в файл на Mac. На сервере копии не остаются.
  • Хранилища, которые вы подключили. Яндекс Диск, Google Диск, S3-совместимые сервисы (Yandex Object Storage, Selectel, VK Cloud, Cloudflare R2, Backblaze B2, AWS или ваш сервер), серверы WebDAV (Nextcloud, ownCloud, Synology, Koofr и другие) и папки на Mac, внешнем диске или NAS. Туда уходят только ваши копии и служебный файл со списком файлов и контрольными суммами. За хранение данных в этих сервисах отвечают их собственные правила.
  • Страницы входа Яндекса и Google. Когда вы подключаете Диск, вход открывается в браузере. CopyHome получает только токен доступа и не видит ваш пароль.
  • GitHub, для автообновления. CopyHome проверяет новые версии на github.com/ilyabazhenov/copyhome и скачивает их оттуда. Как при любом запросе, GitHub видит IP-адрес вашего Mac. Приложение не передаёт при этом никаких сведений о вас или ваших бекапах. Автообновление можно выключить в Настройках, тогда CopyHome обращается к GitHub только по команде «Проверить обновления…».

Яндекс Диск

CopyHome просит доступ только к папке приложения «Приложения/CopyHome» и к сведениям о размере Диска, чтобы показать свободное место. Остальные файлы на Диске приложению недоступны. Если хранилище подключили в ранней версии с доступом ко всему Диску, CopyHome предложит подключить его заново. Отозвать доступ можно в настройках Яндекс ID.

Google Диск

CopyHome запрашивает только область https://www.googleapis.com/auth/drive.file. С ней приложение видит лишь файлы и папки, которые создало само, а остальное содержимое Диска ему недоступно. Ещё оно читает адрес почты аккаунта и занятое место, чтобы показать их в настройках хранилища.

  • Данные из Google Диска используются только для того, чтобы выгружать ваши копии, показывать их список, скачивать их обратно и удалять старые по вашим правилам хранения.
  • Они не передаются третьим лицам, не продаются, не используются для рекламы и для обучения моделей искусственного интеллекта. Данные обрабатываются только на вашем Mac, поэтому люди их не читают.
  • Токен доступа хранится зашифрованным на вашем Mac. Отключить Google Диск можно, удалив хранилище в CopyHome. Отозвать доступ можно на странице myaccount.google.com/permissions.

Использование и передача приложением CopyHome информации, полученной от Google API, соответствуют Правилам в отношении пользовательских данных сервисов Google API (Google API Services User Data Policy), включая требования об ограниченном использовании (Limited Use).

Сайт copyhome.app

На сайте нет cookies, аналитики и счётчиков. Он размещён на GitHub Pages, шрифты загружаются из Google Fonts, а приложение скачивается с GitHub, поэтому эти сервисы видят IP-адрес и браузер, как при любом запросе. Выбранная тема сохраняется только в вашем браузере.

Как удалить данные

Удалите хранилища и проекты в CopyHome, затем само приложение и папку ~/Library/Application Support/fast-backup. Копии на Mac и в хранилищах остаются вашими файлами, их можно удалить как обычно.

Изменения

Если политика изменится, новая версия появится на этой странице с новой датой.
