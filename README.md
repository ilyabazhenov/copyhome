# Лендинг CopyHome

Статическая страница без сборки: откройте `index.html` в браузере или выложите папку на любой хостинг
(GitHub Pages, Netlify, Vercel, обычный nginx).

- `index.html`: русская версия, `en/index.html`: английская. Разметка у них одинаковая, при правке текста меняйте обе.
- `styles.css`: стили. Светлая и тёмная тема заданы токенами в `:root`; по умолчанию тема как в системе,
  кнопка в шапке переключает её и запоминает выбор в браузере.
- `main.js`: переключатель темы, анимации (поток бекапов в шапке, график, терминал) и ссылка на загрузку.
  Строки для JS лежат в `STRINGS` для каждого языка.
- `assets/`: иконка, favicon и картинки для соцсетей `og.png` и `og-en.png` (1200×630).

Перед публикацией:
- вставьте ссылку на `.dmg` в `DOWNLOAD_URL` в начале `main.js`;
- замените относительные `og:image` и `hreflang` на абсолютные адреса сайта (соцсети не понимают относительные).

Шрифты Manrope, JetBrains Mono и Cormorant Garamond подключаются с Google Fonts.
